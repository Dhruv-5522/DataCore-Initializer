# DataCore-Initializer
# Project: Fundamental Booster

### Objective
An interactive Python application designed to capture, process, and analyze user personal data using core programming concepts.

### Project Details & Requirements Covered
- **Detailed Use of print() and input() Functions:** Collected user information like name, age, height, and favorite number, with formatted guiding messages.
- **Data Types, Variables & Operators:** Stored information in appropriate data types and performed calculations (such as calculating the birth year).
- **Type Casting Constructors:** Handled necessary type casting (e.g., casting age to integer and height to float).
- **id() and type() Functions:** Displayed the data type and memory address of each variable in the summary.

### Assumptions
- **Current Year:** We have assumed the current year to be 2026 to calculate the user's birth year based on their age (Birth Year = 2026 - Age).
